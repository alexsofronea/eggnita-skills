# Audit — score existing positioning

Take something that exists — a homepage, landing page, tagline, pitch, bio — and score it against the pattern library, then return prioritized fixes and rewrites of the worst offenders.

## Flow

1. **Ingest the artifact.**
   - URL → fetch it. Paste → use it as-is. Screenshot → read the image.
   - Capture the actual words. Positioning lives in the copy; note layout only where it changes the read (buried hero, competing CTAs).
2. **Identify the business type** (from the artifact or by asking) and pull the matching overlay from [patterns.md](patterns.md).
3. **Score each dimension** in the [patterns.md](patterns.md) scoring table, checking for the 15 failure modes. For each: a score, a one-line reason quoting the artifact, and the rule it violates. Name the before→after **transformation(s)** the page needs from the library in [exemplars.md](exemplars.md#the-beforeafter-transformation-library).
4. **Rank the findings** by impact. A confusing hero outranks a weak testimonial. Lead with the two or three that would move the needle most.
5. **Rewrite the worst offenders.** Don't just diagnose — show the fix. Rewrite the hero, the problem section, the value line, the self-qualification block as they *should* read, applying a concrete formula from [exemplars.md](exemplars.md).
6. **Offer the panel.** For anything the user will act on, offer a pressure-test ([panel.md](panel.md)) — at minimum the rules critic, escalating to ICP personas if the stakes warrant. The user chooses.

## Output shape

A teardown, not a wall of scores. **Be candid and concise** — lead with the blunt verdict, don't cushion a real problem, don't pad. If the positioning is fundamentally broken, the first line says so. Before presenting, run the written verdict and every rewrite through the **`stop-slop`** skill (SKILL.md: "Always run the slop check").

- **The 5-second verdict** — what a stranger takes away, and whether that's what it should be.
- **Scorecard** — the dimension table, each with score + reason.
- **Top fixes (ranked)** — the two or three highest-impact problems, each with the rule and a concrete rewrite.
- **Everything else** — remaining findings, briefly.
- **Next step** — offer the panel, or offer to run **create** for a full repositioning if the audit shows the problem is strategic (wrong customer / no wedge), not just copy.

## The line audit vs create must respect

Audit fixes what's there. If the score reveals the *strategy* is broken — targeting everyone, no real differentiation, wrong category, unowned problem, wrong buyer — the fix lives in [frameworks.md](frameworks.md), not in copy. Say so plainly and offer to switch to **create** ([create.md](create.md)). Don't polish copy on top of broken positioning; name it.
